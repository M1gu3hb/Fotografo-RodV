# The Best Moment

Sitio web de fotografía para Rodrigo Vargas.

## Estado

Dirección visual implementada: identidad, wordmark, sistema tipográfico, portada, portafolio, experiencias, fotolibros, contacto y adaptación responsive. Las fotografías originales se integrarán en la siguiente etapa.

## Desarrollo

```bash
npm install
npm run dev
```

La compilación de producción se genera con `npm run build`.
