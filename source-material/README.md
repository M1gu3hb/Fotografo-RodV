# Material fuente

Estos archivos fueron entregados por el usuario y se conservan para que el proyecto pueda retomarse fuera de la computadora original.

- `PDF THE BEST MOMENTS 2026.pdf`: catálogo real usado para paquetes, prestaciones, fotolibros y extracción de fotografías.
- `Ejemplo.mp4`: recorrido del sitio anterior de Rodrigo, usado como referencia de ritmo visual y animaciones. El sitio actual mantiene una dirección propia.

Son fuentes de consulta. No se publican en Vercel y no deben enlazarse desde el sitio. Para editar precios o entregables, contrastar primero con el PDF y después actualizar `src/data/packages.json`.
